        設定
        
      
        修改後自動儲存，只存在這台電腦。
        

      
        
        版本與更新
        
        
          
          
          
          
        
        
        
        
        每次開啟會自動檢查一次；有新版時右上角會出現提示。
        
      
        

      
        
        影片工具
        
        
        
        
          
          
          
        
        
        
        
        ffmpeg 約 110MB、yt-dlp 約 18MB，下載到程式資料夾。YouTube 下載失敗時先試「只更新 yt-dlp」。
        
      
        

      
        
        影片
        
        
        
        單集固定接 45 秒；全集第一段後接 20 秒、第六段後接 45 秒。
        
        
        
        只加在單集的「影片檔」積木（每個積木可以再自己改）；YT、promo、全集都已經加過，不會再加。剪映的「+6」就是 +6dB，會自動加限幅器，拉高後也不會爆音。0 表示不調整。
        
        
        
        
        全集各段選「只砍片尾」（第一、二、四、五段的預設）時，自動砍掉上面那支 45 秒 promo 的實際長度；這裡填的秒數再加上去（正數多砍、負數少砍），預設 0。選「切在閃白」（第三、六段的預設）時改用閃白或指定時間點。
        
        
        
        
        
          
        
        
        
        按「偵測硬體編碼」查看這台電腦能用哪一種，以及失敗的原因。
        
        
        輸出規格固定 1920×1080、29.97fps、H.264 + AAC。
        
      
        

      
        
        完成提示
        
        
        
        
        
        提示音是程式即時合成的，不使用任何音效檔，沒有版權問題。
        
      
        

      
        
        共用資料夾同步
        
        
        
          
          
          
        
          
        {MMDD}＝月日（1016）、{YYYY}＝年、{MM}＝月、{DD}＝日、{YYYYMMDD}＝完整日期。檔名和「存成 txt」相同。
        
          
          
          
        工具不會建立資料夾。當天資料夾建好後，第一個人按上方「寫入」或「存成 txt」存到當天資料夾，之後大家就會自動同步。開啟自動載入時，每天第一次打開會換成當天的檔案。你修改的同時別人也改過的話，會詢問要用哪一份。
        
        
        
      
        

      
        
        自動切段：AI 補判
        
        
        
        規則沒把握的鏡頭（例如兩段同來源遮罩中間沒遮到、右上角來源字太小比不準），截右上角來源字給 Gemini 讀，跟靜圖的來源字相同就遮。判斷結果會存起來，同一個鏡頭不會重複問。
        
      
        

      
        
        YouTube 上傳
        
        
        
        
        
          自動上傳前要備齊（沒齊就先等，齊了才傳；等的時候每分鐘看一次共用資料夾）
          
          
          
        
        
        
        
        
        
        用戶端 ID、密碼在 Google Cloud 建一個「電腦版應用程式」的 OAuth 用戶端取得（要先啟用 YouTube Data API v3）。預設標記每段都會加，排在文稿的「後臺關鍵字」前面，用英文逗號分隔，合計超過 500 字時後面的截掉。說明欄固定內容接在每段說明最後（API 上傳不會套用 Studio 的上傳預設設定）。
        
      
        

      
        
        自動切段：水印
        
        
        
        1920×1080 透明 PNG，整張蓋上。月份標檔名是年月（例如 202610.png）時，出片會自動改用同資料夾裡節目日期那個月的檔（11 月就用 202611.png），不用每月換。只壓在節目正片上，YT、promo 不壓；正片同時加上「單集影片預設音量」。
