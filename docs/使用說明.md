# 使用說明

畫面上的說明只有一句話，詳細的放這裡。

## 自動切段

按「開始監看」後就不用管：側錄每錄好一個檔，工具就自己看一遍；一段錄完整，就自動遮好、出片；六段都好了再合成全集。

### 來源與輸出

| 欄位 | 說明 |
|---|---|
| 側錄資料夾 | 錄影機存檔的地方。換文稿日期會自動換到那天的資料夾。 |
| 靜圖資料夾 | 放要遮的畫面截圖（見下方「替換畫面」）。沒選＝跟側錄放在同一個資料夾。 |
| 成品資料夾 | 出好的影片放這裡。沒選＝用設定頁的「輸出資料夾」。 |
| 從幾點開始看 | 這個時間以前已經播完的不看（例如 21:50），避免把前一個節目當成本節目。可以填到秒（例如 `21:55:40`），用來避開開場提要。那一刻剛好有一段正在播（例如填 23:00，第 4 段 22:55 就開始了），工具會往前找到那段真正的開頭（最多往前多讀 6 個側錄檔），不會把半段當成一段。時間是側錄檔名時間＋檔內秒數，誤差約一兩秒。 |
| 節目最晚幾點結束 | 最後一段用：過了這個時間、節目畫面沒再出現，就當作播完了。有些天節目結束沒有收黑，只能靠這個判斷。空白＝不用。 |
| 遮罩換圖間隔（秒） | 同一支素材有好幾張截圖時，每隔幾秒換下一張，看起來比較不像定格。只有一張就不換；0＝不換。 |
| 一段錄完就自動出片 | 關掉的話要自己按「出片」。 |
| 六段都好了自動合成全集 | |
| 複製到當天共用資料夾 | 檔名像 `1106-1.mp4`，方便同事檢查。重新出片時會蓋掉舊的那份。 |

### 時間只打數字

要填時間的欄位可以只打數字，離開欄位時自動加上冒號：

- 從幾點開始看、節目最晚幾點結束：`2300`→`23:00`、`930`→`09:30`、`215540`→`21:55:40`
- 壓 BAR 時間、手動遮罩時段、串接影片的開始／結束：`1601-1610`→`16:01-16:10`、`13025`→`1:30:25`；一兩位數是秒
- 手動遮罩另外可打 8 位數的剪輯時間碼：`00160120`→`00;16;01;20`

文稿的段落時間（例如 `2708`）本來就可以只打數字。

### 每段串接

每段出好後自動在後面接東西：節目 →（閃白）→ 你加的影片（可以好幾支，照順序）→ promo。接好的檔放在成品資料夾的「上傳」裡。只有節目本身會調大聲、壓台標；影片和 promo 不動。監看中隨時可以改，改了會重新接一次。

### 替換畫面（靜圖）

- 把要遮的畫面截圖放進對應的「第 N 段」資料夾，工具會在那一段找到長得一樣的畫面，用截圖蓋掉。
- 只在那一段找，是為了不要蓋到別段剛好長得像的畫面（例如只有一行「翻攝 X」的不同新聞）。
- 別段**重播同一支素材**時（畫面幾乎一樣、右上角來源字也一樣、持續 1 秒以上），工具會自動把那一段的截圖拿來用，不用另外放。報告會寫「第 4 段重播了第 1 段的素材」。
- 「每段都比」（直接放在靜圖資料夾裡）：每一段都會找。只放整集都會出現的素材，不要全部丟這裡，否則可能用錯圖（例如 vlog 被蓋成女團的圖）。
- 截圖請用**乾淨的畫面**（從錄影檔截、沒有字幕和台標），因為它會直接蓋上去。
- 同一支素材換了鏡頭（遠景、近景）就比不上，要多截幾張，或用手動遮罩。

### 壓 BAR

下方標題條寫錯時用：選一張新的 BAR 圖（1920×1080 透明 PNG），工具會自己找出舊標題出現的時間，把新圖整張蓋上去。找不到的話可以自己填時間（看成品的時間，例如 `29:55-31:18, 32:00-32:10`）。改完後已經出好的影片要按「重新出片」才會套上。

棚內背板（大螢幕）內容錯誤也可以用這個：做一張只有正確背板、其他地方透明的 PNG，填手動時間。

### 手動遮罩

同事回報哪裡沒遮到，就在這裡補：

- 把時間貼進來，看**成品**的時間。剪輯軟體的時間碼可以直接貼：`00;16;01;20-00;16;10;25`（`;` 是 29.97 掉格、`:` 是不掉格，最後一節是格數），也可以寫 `16:01.6-16:10.8`，好幾段用逗號分開。
- 這段一定會遮，蓋過自動判斷的。
- **記得選要蓋上去的圖**，可以選好幾張：整個畫面都是素材的地方用滿版圖，左邊小框的地方用雙框圖（只蓋小框）。工具會照畫面切開，各自挑最像的那張。
- 沒選圖時，工具會自己挑夠像的（平均 0.5 以上）；找不到就**不遮**，報告會提醒你選圖。
- 圖要放在靜圖資料夾裡（別段資料夾的也可以選）。
- **跳過棚內、自己的圖卡**（打勾）：可以整段填一個時間（例如演唱會混剪 `16:07-20:00`），工具把它切成一個一個鏡頭問 AI，本節目的棚內、主持人、自己做的圖卡不遮，外部素材才遮；AI 不確定的也不遮（寧可少遮）。判成本節目、但有選靜圖的鏡頭，會再比對一次「跟選的靜圖是不是同一支素材」，所以**記得選這段素材的靜圖**（別的節目的棚，例如綜藝節目，才不會被當成本節目）。報告會逐個鏡頭列出遮不遮和理由。**沒開 AI 時這個選項判斷不了，整段都不會遮。**
- 改完會自動重新出片；沒開自動出片的話按「重新出片」。

### 上傳 YouTube

- 影片傳成「私人」，不會直接公開。
- 標題和說明照文稿填，說明最後接設定頁的固定文字；標記＝設定頁的預設標記＋文稿的後臺關鍵字；縮圖用共用資料夾當天的 `1.jpg`、`2.jpg`…；傳完自動加進播放清單。
- 設定頁打開「自動上傳」的話，影片一做好（有接 promo 就等接好）就會自己傳。某一段先不要傳，按那段的「停止自動上傳」，其他段不受影響。
- 片尾、中插廣告、版權確認、發布，還是要到 YouTube Studio 做。

### 判斷報告（report.txt）

成品資料夾裡的 `report.txt`：

- **覆蓋檢查**：每張截圖在側錄裡最像的地方有沒有遮到，`★沒遮` 要看一下。只檢查截圖本身那一格，同一支素材的其他鏡頭查不到。
- **AI：…**：每一個問過 AI 的地方和答案。
- **各階段耗時** 的「AI 補判（問了 N 處）」：那一輪真的呼叫 AI 的次數。

## 段落怎麼認

- 靠下方標題條的文字（OCR）對文稿，知道現在播的是第幾段。
- 同一段的標題可能出現好幾次：開場提要（主持人先念第一條標題幾秒，廣告後才正式開始）、節目後的預告、重播。工具取**有播到文稿這段最後兩條標題**的那一次；都還沒播到（錄製中）就取第一次，除非後面那次長兩倍以上。
- 安全網：沒播到最後標題、又短於 60 秒的不當成一段，不出片；後面還有同一段正在錄的，先等。報告會寫「開場預告，不收」。
- 開場提要還是被當成第 1 段時，把「從幾點開始看」填到秒（正式開始前一點），之前的畫面就不看。

## 自動判斷怎麼運作（寧可少遮）

1. 畫面跟截圖幾乎一樣（0.8 以上），或右上角兩行來源字對得上 → 遮，而且整個鏡頭都遮。
2. 同一個鏡頭裡判斷斷了 8 秒以內 → 補起來。中間**換了鏡頭**就不補，改問 AI（避免蓋到棚內手板）。
3. 沒把握的地方問 AI（設定頁要填 AI 金鑰）：
   - **相鄰鏡頭**：遮罩前後緊接的鏡頭是不是同一支素材。附上這段開頭本節目棚內的畫面，讓 AI 分得出「我們的棚」和別的節目的棚；雙框只看左邊小框，小框是我們自己的圖卡就不接。
   - **空檔**：兩段同一支素材的遮罩中間，右上角來源字是不是一樣。
   - **灰色地帶**：來源字或畫面有幾分像的地方。
   - AI 也說不準就不遮。問過的答案存在 `.autocut\ai.tsv`，重跑不會重問。一集大約問一百多次，每分鐘最多 10 次。
4. 手動遮罩最後套上，一定遮。

一定抓不到、要靠手動遮罩的：同一齣戲但鏡頭不同（跟截圖不像、只有一行「翻攝 Youtube」、離其他遮罩又遠）。

## 設定

| 欄位 | 說明 |
|---|---|
| 影片工具 | 處理影片用的 ffmpeg、yt-dlp（約 130MB），第一次用要先下載。YouTube 影片抓不下來時先按「只更新 yt-dlp」。 |
| promo | 單集後面都接 45 秒那支；全集第一段後接 20 秒、第六段後接 45 秒。 |
| 節目音量要調大多少（dB） | 側錄的聲音比較小。填 6 就跟剪映的「+6」一樣，會自動加限幅，調大也不會破音。0＝不調。只調節目本身，YouTube 影片和 promo 不會再調。單集的「影片檔」積木可以各自改。 |
| 閃白長度 | 段落之間閃白幾秒。 |
| 全集剪掉片尾時多剪或少剪 | 合成全集時，第一、二、四、五段後面的 45 秒 promo 會被剪掉。剪完還留一點或剪過頭時微調：正數＝多剪、負數＝少剪，通常 0。第三、六段是剪在閃白的地方，不受影響。 |
| 出片用什麼加速 | 不確定就選「自動」。影片規格都一樣（1920×1080、29.97fps、H.264＋AAC），只差速度。按「偵測硬體編碼」看這台電腦能用哪一種。 |
| 共用資料夾同步 | 跟同事共用當天的文稿。當天資料夾要先有人建好（工具不會建）；第一個人按「寫入」或「存成 txt」存進去後，大家打開就是同一份。兩個人同時改到時會問你要留哪一份。資料夾名字裡 `{MMDD}`＝月日（1016）、`{YYYY}`＝年、`{MM}`＝月、`{DD}`＝日、`{YYYYMMDD}`＝完整日期。 |
| AI 金鑰（Gemini） | 空白＝不用 AI，只靠規則判斷（會少遮比較多）。模型一般不用改。 |
| YouTube 授權 ID／密碼 | 由負責的人在 Google Cloud 建一個「電腦版應用程式」的 OAuth 用戶端取得（要先啟用 YouTube Data API v3），設定一次就好。 |
| 自動上傳前要備齊 | 勾起來的（縮圖、後臺關鍵字、播放清單）要準備好才會傳；還沒好就先等，每分鐘再看一次。 |
| 每段都要加的播放清單 | 一行一個；`{日期}` 會換成當天日期，例如 `關鍵時刻20261026全集`。 |
| 標記 | 英文逗號隔開，排在文稿的後臺關鍵字前面。YouTube 規定總共最多 500 字，超過的截掉。 |
| 說明欄固定文字 | 接在每段說明最後。用工具上傳時，Studio 的「上傳預設設定」不會套用，所以要填在這裡。 |
| 台標、月份標 | 1920×1080 透明 PNG，整張蓋上。月份標檔名用年月（例如 `202610.png`）的話，到了 11 月會自動改用同一個資料夾裡的 `202611.png`。只壓在節目上，YouTube 影片和 promo 不壓。 |
| 講者名字最多幾個字 | 稿子裡單獨一行、沒有標點、字數在這個以內的，會當成講者名字刪掉（例如「張紹和」）。名字比較長被漏刪時調大。 |
